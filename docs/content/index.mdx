title: Introduction
description: Native HTML components for existing CMS sites. One CSS link plus copied markup, with no changes to the site's own CSS.
---

One CSS link plus copied markup should work in an HTML block in any CMS — Drupal, WordPress, Craft, Optimizely or Sitevision — without a single change to the site's own CSS.

The core is an HTML contract: elements, ARIA, parts and states. CSS and JS are swappable reference implementations. Every component has a contract file that the tests, CSS warnings, editor validation and this documentation are derived from.
