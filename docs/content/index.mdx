**Back to the basics.** Accessible, fast and compatible is usually sold as a compromise: pick it, and accept something that looks plain and feels dated. We don't accept that trade.

- **Accessible** — proven by an open, executable contract that any implementation can be tested against.
- **Fast** — zero JavaScript by default, a few hundred bytes of CSS per component.
- **Compatible** — native HTML on Baseline browser features. Works in any CMS, framework or old theme.
- **And it still looks and feels great.**
