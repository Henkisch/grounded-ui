## Get it, check it, prove it

An agent writes an email field. It looks right, and axe reports nothing:

```text
text-field — 9/10 outcome rules pass, axe: 0 violation(s)
  FAIL text-field/error-reaches-control (normative) If there is an error message, its text
       reaches the control's accessible description or name.
       the error text "enter a complete email address …" is in
       neither the accessible name nor the description of
       <input type="email" id="email">
```

A screen reader user would hear "Email, invalid" and never the reason. One attribute later:

```text
text-field — 10/10 outcome rules pass, axe: 0 violation(s)
```

Every rule links to the WCAG criterion, ARIA pattern or HTML spec it comes from. The check judges what the browser actually exposes, so any markup that gets the result right passes.

## What gets shipped without it

We ran the contracts on ten real implementations. Well-built libraries pass. Typical CMS markup doesn't, in ways axe doesn't report:

- **Drupal core:** the inline error never reaches the field, and by default an invalid field has no message tied to it. [Report](/reports/drupal)
- **Bootstrap:** validation errors never reach the field; a placeholder is the only visible label. [Report](/reports/bootstrap)
- **Elementor Pro:** two forms on one page share ids, so a label names the wrong field. [Report](/reports/elementor)
- **WordPress:** Twenty Twenty's menu modal has no dialog role or name. [Report](/reports/wordpress-core)

## Back to the basics

Accessible, fast and compatible is usually sold as a compromise. We don't accept that trade.

- **Accessible:** proven by an open, executable contract.
- **Fast:** zero JavaScript, a few hundred bytes of CSS per component.
- **Compatible:** native HTML on Baseline features, in any CMS or framework, measured the same in Chromium, Firefox and WebKit.
- **And it still looks and feels great.**

## For AI agents

Add the Grounded UI MCP server and skill to your coding agent. It reads a component's contract, builds from the reference markup, and runs the check on its own HTML until the verdict is PASS. [Set it up](/getting-started/ai-agents).

Every page is also available as Markdown (add `.md` to the URL), indexed in [`llms.txt`](/llms.txt).

## What Grounded UI is not

- Not a component library to lock into: the contracts work on any markup.
- Not a replacement for axe or audits: we run axe, and add the component rules it can't know.
- Not a certification of whole sites: we prove components, not pages.
- Not a new standard competing with W3C: we build on WCAG, the ARIA Authoring Practices and ACT, and contribute back.
