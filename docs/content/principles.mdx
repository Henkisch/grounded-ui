## Regler som styr all kod

- Tillstånd syns i DOM:en, native först. JS rör aldrig klasser. CSS kräver aldrig JS.
- Styling hakar bara på `data-component`, `data-part` och `data-variant`. Klassattributet är fritt åt sajten.
- Allt i `@layer` och `@scope`, `:where()` för noll specificitet. Ingen global reset, inga nakna elementselektorer.
- Inga färgvärden. Bara `currentColor`, `inherit` eller custom property.
- `em` och `lh`, inte `px`. Logiska egenskaper.
- Inga beroenden, inga polyfills, inget byggsteg i det som levereras.

Reglerna kontrolleras av stylelint i varje bygge.

## Lagerordning

```css
@layer grund.core, grund.components, grund.warnings;
```

Ordningen deklareras först i `core.css`, eftersom vissa plattformar aggregerar och omordnar CSS. Sajtens egen CSS ligger utanför lagren och vinner alltid, utan `!important`.

## Budgetar som failar bygget

| Sak | Budget |
| --- | --- |
| Kärn-CSS, minifierad och brotlad | högst 3 kB |
| CSS per komponent | högst 1,5 kB |
| JS per komponent | högst 1 kB, noll är utgångsläget |
| Externa beroenden | 0 |
| CLS-bidrag | 0 |

Storleksdiff redovisas i varje pull request.
