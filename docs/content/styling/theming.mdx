---
title: Theming
description: Every component takes its font and colours from your site, and exposes custom properties for the rest.
---

grund-ui has no theme of its own. Text and borders use `currentColor`, backgrounds are transparent or the browser's `Canvas`, and sizes are in `em` — so a component placed on your site already looks like it belongs there.

## Custom properties

When you want more control, set the component's custom properties from your own CSS. Each component page lists them, with defaults, under **Custom properties**.

```css
/* your-site.css */
[data-component] {
  --grund-radius: 0;
  --grund-border-color: #6b6b6b;
  --grund-focus-color: #0b57d0;
}

[data-component="dialog"] {
  --grund-dialog-bg: #fffdf7;
  --grund-radius-large: 0.25rem;
}
```

No `!important` and no extra specificity: grund's own rules sit in a lower cascade layer, so any rule of yours wins.

## Scope a theme

Custom properties inherit, so you can theme one area of a page:

```css
.site-footer {
  --grund-border-color: currentColor;
  --grund-control-bg: transparent;
}
```

## Overriding a part directly

Target the same hooks the components use. Your selector wins even though it's no more specific:

```css
[data-component="text-field"] [data-part="label"] {
  text-transform: uppercase;
  letter-spacing: 0.05em;
}
```

See [cascade layers](/styling/cascade-layers) for why this works.
