## Rules for all code

- State is visible in the DOM, native first. JS never touches classes. CSS never requires JS.
- Styling hooks only on `data-component`, `data-part` and `data-variant`. The class attribute belongs to the site.
- Everything in `@layer` and `@scope`, `:where()` for zero specificity. No global reset, no bare element selectors.
- No colour values. Only `currentColor`, `inherit` or a custom property.
- `em` and `lh`, not `px`. Logical properties.
- No dependencies, no polyfills, no build step in what ships.

stylelint enforces these rules on every build.

## Layer order

```css
@layer grounded.core, grounded.components, grounded.styled, grounded.warnings;
```

The order is declared first in `core.css`, because some platforms aggregate and reorder CSS. The site's own CSS sits outside the layers and always wins, without `!important`.

## Budgets that fail the build

| Item | Budget |
| --- | --- |
| Core CSS, minified and brotli-compressed | 3 kB max |
| CSS per component | 1.5 kB max |
| JS per component | 1 kB max, zero by default |
| External dependencies | 0 |
| CLS contribution | 0 |

Every pull request reports the size diff.
