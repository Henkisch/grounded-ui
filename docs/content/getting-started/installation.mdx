title: Installation
description: Link the core CSS once, then one stylesheet per component. No build step, no JavaScript.
---

grund-ui ships as plain CSS files and copyable HTML. There is nothing to compile and nothing to run.

## Link the stylesheets

Add the core once per page, then the stylesheet for each component you use:

```html
<link rel="stylesheet" href="/grund-ui/core/tokens.css">
<link rel="stylesheet" href="/grund-ui/core/core.css">
<link rel="stylesheet" href="/grund-ui/components/text-field/styles/text-field.css">
<link rel="stylesheet" href="/grund-ui/components/dialog/styles/dialog.css">
```

## Base or styled

Every component comes in two files:

| File | What it holds | Link it |
| --- | --- | --- |
| `<slug>.css` | **Base**: layout of the parts, touch targets, focus ring, what the contract needs | Always |
| `<slug>.styled.css` | **Styled**: radius, padding, borders, type sizes, animation | When you want grund's look |

Base alone gives a correct, accessible component that looks like your site and the browser's defaults. Add the styled file for a finished look, then adjust it with [custom properties](/styling/theming). Each component page shows both in the **Styled** and **Base** tabs.

```html
<link rel="stylesheet" href="/grund-ui/components/dialog/styles/dialog.css">
<link rel="stylesheet" href="/grund-ui/components/dialog/styles/dialog.styled.css">
```

Order doesn't matter. Every file declares the same cascade layer order, so a CMS that aggregates or reorders stylesheets can't break it.

## Get the files

Until the first npm release, copy `core/` and the component folders you need from the [repository](https://github.com/Henkisch/grund-ui) into your theme. Each component folder holds:

<FileTree>

- components/
  - dialog/
    - contract.yaml
    - markup/
      - basic.html
    - styles/
      - dialog.css
      - dialog.styled.css

</FileTree>

`styles/` is what you link: the base file, and optionally the styled one. `markup/` is the HTML you copy. `contract.yaml` is the rulebook the markup follows.
