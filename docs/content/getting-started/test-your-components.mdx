---
title: Test your components
description: Run grund's contracts against rendered HTML from any library, theme or CMS, and see which rules pass.
---

The contracts test **rendered HTML**, not source code. So they work the same on a React app, a WordPress theme or a 15-year-old CMS template.

## 1. Run it

```sh
npx grund-conformance https://your-site.example/contact
```

Every component on the page is checked against its contract, and axe runs on the same element. The output lists each rule that fails, and whether axe caught the same component:

```text
  text-field <div class="field"> — 13/15 rules pass, axe: 0 violation(s)
    FAIL TF-07 (normative) The label's for matches the control's id.
         for="town" but id="city"
```

## 2. Point it at your markup

grund's own markup is recognised as is. For anything else, write a **binding**: which selector matches each part of the component.

```yaml
# my-theme.text-field.binding.yaml
component: text-field
implementation: My theme
root: .form-row
parts:
  label: .form-row__label
  description: .form-row__help
  control: .form-row__input
  error: .form-row__error
```

```sh
npx grund-conformance page.html --binding my-theme.text-field.binding.yaml
```

Each component page lists its parts under **Test your implementation**.

## 3. Read the result

- **Normative** rules are required by a standard; the rule links to it. A failure is an accessibility bug.
- **Recommended** rules are grund's judgement, with the reasoning linked. A failure is worth a look, not automatically a bug.
- A failure where axe reported nothing is exactly what the contracts are for: component-level problems general tools can't know about.

See the [conformance reports](/reports/govuk-frontend) for a full run against a real library.

## In CI

The runner is a plain Node API, so it drops into an existing Playwright suite:

```js
import { test, expect } from '@playwright/test';
import { checkPage, failures } from 'grund-ui/conformance/src/index.mjs';

test('forms meet the grund contracts', async ({ page }) => {
  await page.goto('/contact');
  expect(failures(await checkPage(page))).toEqual([]);
});
```
